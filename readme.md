# Pengumpulan Tugas Mata Kuliah Desain & Pemrograman Web

## Deskripsi

Repositori ini berisi kumpulan tugas praktikum dan _source code_ untuk mata kuliah **Desain & Pemrograman Web**. Proyek di dalam repositori ini mencakup implementasi teknologi _Front-End_ (HTML, CSS, Javascript) hingga _Back-End_ (PHP, MySQL) yang dikerjakan secara bertahap sesuai modul perkuliahan.

---

## 📁 Struktur Modul

| Folder | Topik | Deskripsi Singkat |
|---|---|---|
| `Modul 1 - 3 : HTML` | HTML | Struktur web dasar, tabel, form, dan elemen semantik HTML5 |
| `Modul 4 - 6 : CSS` | CSS | Styling, layouting (Flexbox/Grid), dan antarmuka responsif |
| `Modul 7 : Javascript` | Javascript | Interaktivitas DOM, event handling, dan logika _client-side_ |
| `Modul 8 - 12 : PHP` | PHP & Database | Server-side scripting, koneksi MySQL, sistem CRUD lengkap, OOP, dan Prepared Statement |

---

## 🛠️ Teknologi yang Digunakan

- **HTML5** — Struktur dan semantik halaman web
- **CSS3** — Tampilan, layout, dan desain responsif
- **Javascript (Vanilla)** — Interaktivitas dan manipulasi DOM
- **PHP** — Pemrograman server-side (Prosedural & OOP)
- **MySQL / MariaDB** — Sistem Manajemen Basis Data Relasional
- **MAMP** — Lingkungan pengembangan lokal (Mac, Apache, MySQL, PHP)

---

## 🗄️ Fitur Utama (Modul PHP)

- ✅ Koneksi database menggunakan `mysqli` (Prosedural & OOP)
- ✅ Sistem **CRUD** lengkap untuk tabel `t_dosen`, `t_mahasiswa`, dan `t_matakuliah`
- ✅ **Prepared Statement** untuk keamanan dari serangan SQL Injection
- ✅ **Fitur Pencarian** data berdasarkan nama
- ✅ **Class Database** khusus untuk manajemen koneksi (OOP)
