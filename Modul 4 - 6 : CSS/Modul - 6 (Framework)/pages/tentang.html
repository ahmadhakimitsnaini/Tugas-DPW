Apa itu Bootstrap?

Bootstrap adalah framework CSS open-source paling populer di dunia yang dikembangkan oleh tim Twitter. Framework ini menyediakan kumpulan komponen HTML, CSS, dan JavaScript yang siap pakai untuk membangun website responsif dan mobile-first dengan cepat.

Bootstrap menggunakan sistem grid 12 kolom yang fleksibel, serta menyediakan ratusan utility class yang memungkinkan developer membangun interface tanpa perlu menulis CSS dari nol.

Timeline Perkembangan Bootstrap

2011
Bootstrap v1.0

Dirilis oleh Mark Otto dan Jacob Thornton dari Twitter. Awalnya disebut "Twitter Blueprint".

2013
Bootstrap v3.0

Memperkenalkan pendekatan mobile-first. Desain flat dan grid responsif yang lebih matang.

2018
Bootstrap v4.0

Beralih ke Flexbox, menambahkan utility classes, dan menggunakan Sass sebagai preprocessor.

2021 — Sekarang
Bootstrap v5.0+

Menghapus ketergantungan jQuery, menambahkan CSS custom properties, komponen Offcanvas, dan RTL support.

FAQ

Pertanyaan yang Sering Diajukan

Ya, Bootstrap adalah framework open-source yang sepenuhnya gratis. Anda bisa menggunakannya untuk proyek pribadi maupun komersial tanpa biaya apapun.

Tidak. Bootstrap 5 telah menghapus ketergantungan pada jQuery dan menggunakan JavaScript vanilla murni, sehingga lebih ringan dan modern.

Ada beberapa cara: (1) Via CDN — cukup tambahkan link CSS dan JS di HTML, (2) Download file dan simpan lokal, atau (3) Install via npm: npm install bootstrap.

CSS biasa ditulis dari nol oleh developer. Bootstrap menyediakan "library" CSS yang sudah jadi, berisi komponen dan utility class sehingga pengembangan jauh lebih cepat. Namun CSS biasa memberikan fleksibilitas penuh.
Tips: Kunjungi dokumentasi resmi Bootstrap di getbootstrap.com untuk referensi lengkap semua komponen dan utility class yang tersedia.
