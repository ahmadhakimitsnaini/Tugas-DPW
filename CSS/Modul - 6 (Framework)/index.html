Modul Praktikum CSS Framework

Belajar Bootstrap 5

Framework CSS paling populer di dunia untuk membangun website responsif, modern, dan profesional dengan cepat menggunakan komponen siap pakai.

Mulai Belajar Lihat Komponen

Mengapa Bootstrap?

Keunggulan Bootstrap dibanding CSS biasa

Responsif

Sistem grid 12 kolom otomatis menyesuaikan tampilan di semua ukuran layar — mobile, tablet, dan desktop.

Komponen Siap Pakai

Ratusan komponen UI — navbar, card, modal, carousel, form, button — langsung bisa dipakai tanpa kode dari nol.

Pengembangan Cepat

Utility classes seperti mt-3, text-center, d-flex mempercepat styling tanpa pindah file CSS.

Tutorial #1

Cara Menambahkan Bootstrap ke Halaman HTML

Ada dua cara utama menggunakan Bootstrap: via CDN (paling mudah) atau download file lokal.

1
Tambahkan link CSS di <head>

Salin tag <link> Bootstrap dari getbootstrap.com ke bagian head HTML Anda.

2
Tambahkan script JS sebelum </body>

Bootstrap membutuhkan JavaScript untuk komponen interaktif seperti modal dan dropdown.

3
Mulai gunakan class Bootstrap

Tambahkan class seperti container, row, col pada elemen HTML Anda.

index.html 
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" 
    content="width=device-width, 
    initial-scale=1.0">
  <title>Halaman Saya</title>

  <!-- Bootstrap 5 CSS -->
  <link href="https://cdn.jsdelivr.net/
  npm/bootstrap@5.3.3/dist/css/
  bootstrap.min.css" rel="stylesheet">
</head>
<body>

  <h1 class="text-primary">Halo!</h1>

  <!-- Bootstrap 5 JS -->
  <script src="https://cdn.jsdelivr.net/
  npm/bootstrap@5.3.3/dist/js/
  bootstrap.bundle.min.js">
  </script>
</body>
</html>
